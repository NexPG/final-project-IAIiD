## Правила работы с документацией

1. `TZ.md` — единственный источник истины по требованиям. Изменения фиксируются в истории изменений.
2. Документы этапов дополняют TZ, но не противоречат ему.
3. Все числа в отчёте и презентации должны быть подтверждены артефактами экспериментов.
4. Локальные материалы курса (`docs/project_plan/`, `docs/presentations/`) не входят в репозиторий и исключены через `.gitignore`.
5. Сырые внешние данные лежат в `data/external/` и не коммитятся; см. `data/external/README.md`.
