# Ноутбуки

Ноутбуки используются для EDA, экспериментов и error analysis. Они не являются production-кодом.

Планируемые файлы:

```text
notebooks/
├── 01_eda.ipynb
├── 02_baseline.ipynb
├── 03_transformer.ipynb
└── 04_error_analysis.ipynb
```

## Правила

1. Нумерация по порядку выполнения.
2. Ноутбук должен запускаться сверху вниз на подготовленном окружении.
3. Большие данные не коммитятся; пути берутся из `data/`.
4. Выводы переносятся в `docs/experiments.md`.
5. Перед коммитом очищать outputs (например, `nbstripout`).
