# Скрипты

CLI-скрипты для воспроизводимых операций.

Планируемые файлы:

| Скрипт | Назначение |
|---|---|
| `validate_data.py` | проверка схемы, дублей, утечек и распределения классов |
| `prepare_data.py` | очистка, PII-маскирование, split |
| `train.py` | обучение baseline/transformer |
| `evaluate.py` | метрики, confusion matrix, classification report |
| `predict.py` | локальная проверка модели на примерах |
| `smoke.py` | smoke-проверка запущенного API |

## Правила

1. Скрипты не содержат секретов.
2. Все параметры передаются через аргументы или конфиг.
3. Каждый запуск логируется в MLflow.
4. Скрипты должны работать на чистом окружении по инструкции из README.
